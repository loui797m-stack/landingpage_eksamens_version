# PULSE Core – landingpage V2

Forbedret landingpage for fitnessarmbåndet **PULSE Core** (fiktivt produkt, 1.299 kr.). Projektet er min eksamensopgave på 1. semester af Multimediedesigner-uddannelsen (e26) og viser udviklingen fra første version (V1) til anden version (V2) i både UX/UI design og kode.

> **Case:** Landing Page

> **Navn:** Louise Dalsgaard

> **Uddannelse og semester:** Multimediedesigner, 1. semester

> **Afleveringsdato:** 9. dec 2026
